# Numerical basis for the paraglider CFD path

Current authoritative status: the face-centred staggered MAC solver is the product
default. The collocated control-volume work below remains connected only as an
explicit experiment; high-incidence PlanB runs expose an incompatible persistent
cell/face pressure mode. Its manufactured tests remain useful research evidence,

## Geometry and topology

The CAD model is a collection of oriented surface patches, not a watertight solid. A triangle normal defines a local minus-to-plus direction. Each resolved fabric cut partitions a Cartesian control volume into fluid fragments. Pressure belongs to a fragment, not necessarily to a Cartesian cell, because distinct fluid regions within one cell must retain independent states.

An opening is represented by the absence of fabric. No parity test or inside/outside classification is valid for this model. Surface preprocessing therefore asks only which triangles intersect a cell/face and how they partition local fluid connectivity.

Regular cells use implicit Cartesian topology. Irregular cells carry compact fragment, aperture, blocked-face, and fabric-patch arrays. A sheet coincident with a Cartesian face suppresses that implicit face connection while retaining two ordinary full-volume cells; partial coverage produces one record per connected fluid opening. At the finest level, a deterministic local microcell graph may recover multi-fragment topology at sheet endings and junctions. All microcells remain fluid and only exact triangle crossings remove graph edges, so this is neither solid voxelization nor parity filling. Reaching the finest level without a valid topology is a grid-generation error, never permission to connect or merge regions.

## Finite-volume pressure operator

For two connected fluid control volumes `i` and `j`, an open aperture of area `A` and representative centre distance `d` contributes the symmetric conductance

```
g_ij = A / d
```

to the integrated pressure operator. The volume-normalized Laplacian is

```
(L p)_i = (1 / V_i) sum_j g_ij (p_i - p_j)
```

The divergence and velocity correction must use the same oriented aperture fluxes. This compatibility is necessary for conservation. Fabric patches do not create graph edges; their prescribed normal mass flux is zero for a stationary impermeable sheet.

At a 2:1 AMR interface, the geometric coarse aperture flux is replaced by the sum of the corresponding fine-aperture fluxes. The composite operator must enforce this during every matrix-vector product and correction, not by projecting each level independently and reconciling fields afterwards.

The CUDA solve is matrix-free PCG. Its current additive preconditioner applies the fine operator diagonal and restricts residuals geometrically into level-zero cell aggregates. The aggregate operator is Galerkin: every regular, coarse/fine, and EB conductance contributes to its diagonal and edge coefficients. Conservative fragment merges can produce aggregate edges that are not immediate Cartesian neighbours, so those edges remain in a compact nonlocal list rather than being discarded. Components that cannot reach the X-max pressure outlet receive one deterministic positive gauge coefficient; this removes each component's constant nullspace without opening a path through fabric.

## Small control volumes

Tiny cut fragments create severe explicit stability limits and poorly conditioned pressure equations. The initial stabilization joins adjacent tiny fragments only through actual apertures, then merges the group into an appropriate larger fluid neighbour. A fabric surface is not an open aperture, so the operation cannot cross sides. Merge chains resolve to one root, and volumes are accumulated conservatively into that representative. A group with no external fluid aperture remains an explicitly counted pressure-static pocket rather than being connected through fabric.

## AMR layout

Refinement is static for a run and always ratio two. Cells within a brick are uniform. Bricks are located using integer coordinates in per-level hash tables. Field allocations are contiguous per level and per component; normal CUDA kernels use structured brick indexing, while only compact EB work lists use irregular indirection.

The global timestep is set by the configured CFL, finest active spacing, and a GPU maximum reduction over current regular AMR velocity. There is no time subcycling in version 1. Compact EB graph transport separately bounds its local Courant and explicit molecular-diffusion contribution. Precomputed nearest same-axis graph links provide upstream, second-upstream, and downstream aperture states for a minmod-limited MUSCL update when the complete directed chain exists; incomplete or junction chains use the donor fallback. The combined explicit update is also restricted to its actual same-side stencil extrema because independently limited advection and diffusion coefficients need not sum to a convex update. This is a monotone discretization rule, not an absolute speed cap; pressure projection can still create a new compact velocity extremum, which remains visible to diagnostics and the following timestep selection.

### Historical collocated control-volume experiment

The imported PlanB conservative path exposed a second compatibility issue after the pressure feedback was fixed. Incrementing already-projected faces retained aperture-specific pressure corrections that have no exact representation in one collocated control-volume vector; rebuilding faces absolutely discarded the pressure/velocity coupling and generated a second large startup impulse. The implemented reconstruction is instead `R(U) + G_face(p_previous) - R(G_cell(p_previous))`: interpolate the advanced control-volume vector, remove the cell-averaged preceding correction, and restore the exact preceding face-normal correction. This is Rhie-Chow-like pressure/velocity coupling for the hybrid structured/compact topology. A deterministic multilevel test reproduces every projected regular and special velocity to `3.73e-8` FP32 and `6.94e-17` FP64. The first evolved PlanB pressure load falls from roughly 10.2 kN with absolute reconstruction to about 1.21 kN after pressure-compatible geometric face weighting. The corrected 1,000-step FP32 run reaches 1.934585 s with regular/compact maxima 12.244/12.630 m/s, max/RMS divergence `1.99e-4 / 3.93e-6 s^-1`, net flux `-1.48e-4 m^3/s`, 16.72 ms last measured step (14.03 ms projection), and 651.34 MiB persistent storage. At 200 steps / 0.332948 s, FP32/FP64 total streamwise force differs by about 0.24 ppm; FP64 uses 1224.78 MiB. Conservative cell gradients deliberately reject geometry modes beyond condition number `1e4` in both precisions; rank is a property of the stencil geometry, not floating-point epsilon. These are archived collocated-path results. The face-MAC preprocessing originally took about 75 seconds because coarse/fine link deduplication was O(N²); the current hash implementation removes that cost while retaining all exact same-side BVH tests. The impulsive initialization transient and grid/domain/force convergence remain trust blockers for imported wings.

The imported 1.3 m cylinder exposed a non-orthogonal aperture case in which the two connected control-volume centroids have the same coordinate along the nominal Cartesian face axis even though their full three-dimensional positions differ. Dividing by axial separation is undefined there and previously aborted preprocessing. Composite face reconstruction now uses exact normal-coordinate interpolation when that geometry is resolved and the face lies between its endpoints; otherwise it uses bounded inverse distance to the actual face centroid. A deterministic geometry test covers both paths. The historical collocated cylinder experiment remained stable through 1,000 FP32 steps; it is not a production or converged-load result.

### Production face-centred fabric-safe transport

Ordinary MacCormack/semi-Lagrangian sampling is invalid when a backtrace or interpolation stencil crosses fabric because a geometrically nearby point may be in a disconnected pressure/velocity region. Static preprocessing marks every MAC face centre within 2.5 local cells of fabric and tests its six one-cell Cartesian segments with the triangle BVH. Bits 0..5 of one byte store the open same-side links and bit 6 marks the fabric band. Marked faces use a bounded minmod-limited linear reconstruction when their upstream, second-upstream, and downstream segments are all open on the same side; missing sheet-edge, boundary, or level-transition links revert only that local contribution to the first-order donor update. Diffusion is also restricted to open links. All other faces use bounded MacCormack advection with RK2 characteristics, the finest-brick hash, and Smagorinsky diffusion. The global displacement is bounded below one cell, so the unmarked far-field stencil cannot reach the sheet. This prevents cross-fabric donor data without per-step triangle traversal. Same-level stencils cross brick boundaries instead of clamping, and every level's forward state is complete before the MacCormack correction reads it. A tangential staggered lattice ends half a cell short of a coarse brick boundary; using the nearest coarse value there produced a 0.0266 m/s defect in an exactly linear characteristic. Cross-level velocity and eddy-viscosity samples now use a one-sided linear extension, and reverse MacCormack correction is disabled locally when its trace changes lattice. The same 1,728-interface manufactured case now has about `4.8e-8` m/s FP32/FP64-coordinate error after both advection and linear diffusion. At a 2:1 interface, compact normal-flux tiles gather from transported fine MAC faces and scatter projected values back to fine faces plus an aperture-weighted coarse mean. Irregular aperture velocities advance on a separate compact fluid-connectivity graph: adjacent implicit MAC faces and aperture states form the local fragment velocity, complete same-axis aperture chains use bounded MUSCL transport, and chain endings/junctions use the donor fallback. Component-collocated weighted least squares reconstructs all nine velocity derivatives at graph nodes; the symmetric tensor magnitude supplies compact Smagorinsky dissipation. Production reconstructs each surface patch side's arbitrary-orientation tangential velocity and obtains `u_tau` by solving Spalding's smooth-wall law continuously through the viscous/log layers. The `rho A u_tau^2` impulse uses exact component carrier weights, and its opposite reaction is retained with source triangle/face provenance. The older implicit molecular no-slip flux remains a validation twin, including face-aligned sheets with no aperture edge. None of these graphs contains a fabric crossing or imposes irregular indirection on far-field cells.

### Historical collocated control-volume experiment (continued)

The conservative replacement separates momentum state from mass-flux state. Each actual pressure control volume—regular cell or split fragment—owns one vector momentum value. Projected Cartesian MAC faces and compact apertures carry only normal mass flux, so an ordinary/fragment boundary is one shared finite-volume face with the same upwind momentum flux applied to both endpoint volumes. CUDA evaluates ordinary same-level faces from implicit brick coordinates and materializes only 2:1 tiles plus EB/perimeter work lists; it therefore preserves a fast regular path and avoids a full-domain graph. The manufactured conservation, dissipation, and CPU/GPU parity results below remain valuable research evidence. This experiment is not the production/default path because imported-wing high-incidence stability failed; the face-centred path above is production.

Cell-to-flux reconstruction closes the pre-projection half of the coupling. Ordinary centred faces are implicit; regular/fragment perimeter faces and every 2:1/EB aperture use the face's position between the two actual control-volume centroids. CPU/GPU errors are `1.49e-8` FP32 (`2.78e-17` FP64) across 1,536 2:1 tiles and `1.49e-8` FP32 (`6.94e-18` FP64) on the EB fixture. A face-aligned sheet remains exactly zero-flux even when its two cell states are opposite. The composite projection reduces a reconstructed multilevel field's max divergence from `1.4` to about `4.5e-5 s^-1` at the FP32 correction floor (`3.83e-11 s^-1` FP64). The reverse coupling is a direct finite-volume pressure impulse on the persistent state, not an average of corrected faces: open internal faces use one interpolated face pressure with equal/opposite endpoint impulses; Neumann domain faces use the cell pressure while the X-max pressure outlet uses its zero reference; fabric gives the plus fluid `+p_plus A n` and the minus fluid `-p_minus A n`. Thus the total fluid reaction is exactly `-(p_minus-p_plus) A n`. The closed face-aligned two-pressure fixture cancels to zero pointwise when its physical boundary faces are included, and its open-boundary diagnostic matches the opposite CAD load under either winding. The multilevel internal impulse conserves to `3.74e-9` FP32 / `5.12e-15` FP64 and CPU/GPU state parity is `1.67e-8` / `2.78e-17`; the live projection-pressure pointer updates the persistent state with `3.82e-7` / `8.88e-16` parity.

The composed replacement timestep now runs wholly on resident device state in the sequence transport -> Smagorinsky/molecular diffusion -> implicit smooth-wall shear -> cell-to-flux reconstruction -> physical boundary conditions -> composite projection -> projection-consistent pressure feedback. The initial direct wall implementation evaluated each Spalding patch from the old velocity and accumulated an explicit Euler impulse into its parent control volume. On a real wing, many CAD patches can share one small CV; their summed stiffness could reverse tangential velocity and create the alternating leading-edge pressure mode seen at negative AoA. The replacement freezes the Spalding coefficient over the step, assembles `K = sum k (I-nn^T)`, and solves `(I + dt K/V) u_new = u_old` with a three-by-three Cholesky factorization per active GPU control volume. It is unconditionally dissipative for the frozen coefficient, has no artificial velocity clamp, and its per-patch `k (I-nn^T) u_new` reactions close the fluid impulse. A deterministic `dt=1000 s` fixture verifies no reversal, energy loss, CPU/GPU parity, and reaction conservation. Full-wing -6 and -3 degree PlanB runs remain bounded through 1,500 steps with decaying temporal delta-Cp change, beyond the prior collapse window.

The later full-wing collapse had a separate cause: explicit finite-volume Smagorinsky diffusion used the advective timestep even where a valid compact EB connection had centre distance far below `h`. The actual graph rate `sum(nu A/d)/V` reached about `3325 1/s` during the -6-degree startup. The GPU path now accumulates that rate over structured, compact regular, coarse/fine, and EB connections, freezes the viscosity for the global step, and applies equal/opposite pair fluxes in `ceil(dt rate/0.7)` substeps. Startup uses seven substeps and steady flow returns to one. A manufactured rate-0.333333 fixture at `dt=5 s` selects three substeps, reduces energy from `5.18875615` to `5.10463743`, and conserves momentum to `1.19e-7` FP32. A 1,200-step PlanB -6-degree rerun reaches `t=2.154880 s` with regular/EB maxima `21.428/20.595 m/s`, volume-weighted RMS divergence `4.13e-6 s^-1`, and no recurrence of the old 960--1050-step collapse. This is the missing explicit diffusion stability condition, not a fail-closed guard.

## Surface forces

For a patch with normal `n` from minus to plus,

```
delta_p = p_minus - p_plus
F_patch = delta_p A n
```

Reversing triangle winding changes `n` to `-n` and swaps plus/minus, leaving `F_patch` unchanged. Source-triangle values are area-weighted sums of their embedded patches. The pressure coefficient is based on the configured freestream dynamic pressure

```
q_inf = 0.5 rho U_inf^2
Cp = (p - p_inf) / q_inf
```

Whole-wing force/moment accumulation uses double precision. Reference coefficients are undefined unless a reference area is explicitly supplied. Pressure and implicit Spalding smooth-wall shear are accumulated and reported separately; skin friction is present, but a profile-scale boundary-layer/transition validation is still required before calling its drag quantitatively trustworthy.

## Precision policy

Production velocity, pressure, turbulent viscosity, and temporary GPU fields use FP32 for an Ada/RTX 4090 target. Geometry clipping/BVH construction uses CPU FP64. Validation compares the GPU FP32 operator with analytical or CPU FP64 results; tolerances must follow measured conditioning and convergence rather than being loosened to accept changed output.
