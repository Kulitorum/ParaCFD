# ParaCFD

ParaCFD is a C++20/CUDA/Qt6 aerodynamic CFD application for stabilized paraglider geometry imported from STEP. It treats canopy skins, ribs, diagonals, and panels as zero-thickness, two-sided impermeable fabric; fluid exists on both sides, intentional CAD openings remain open, and no solid-volume filling or artificial extrusion is used.

## Physical model

The intended workflow is one-way coupling:

```
XPBD equilibrium -> STEP export -> ParaCFD preprocessing -> static CFD run
```

OpenCascade remains isolated in the geometry layer. STEP faces are tessellated in SI metres, with source-face provenance retained on every triangle. Triangle winding defines that triangle's local minus-to-plus normal only. Reversing winding swaps the pressure sides and normal together, leaving the physical pressure force invariant:

```
F = (p_minus - p_plus) A n
```

Missing triangles are openings. There is no separate interior-air material: ram-air cells, crossports, and the external flow contain the same fluid.

## Geometry preprocessing

- `TriMesh` stores positions, indices, source STEP face IDs, and optional per-corner UV coordinates.
- `TriangleBvh` is a static double-precision CPU BVH supporting cell AABB queries, segment intersections, nearest-surface queries, and distance queries.
- Runtime geometry is placed before BVH construction. Normals use the affine inverse transpose.
- CAD preprocessing is static. CUDA timesteps do not traverse CAD, rebuild topology, or intersect triangles.

The OpenCascade linear deflection is exposed in the paraglider configuration. The current default is 2 mm, which is still substantially finer than the initial 62.5 mm CFD surface cells and avoids unnecessary million-triangle previews. It should eventually be derived from finest CFD spacing.

`naca_step_generator` creates deterministic finite-span, closed four-digit NACA validation wings through OpenCascade. It accepts the profile code, chord, span, and section sampling on the command line and writes an ordinary millimetre-based STEP file that returns through the same importer, placement, tessellation, BVH, AMR, and EB path as external CAD. `--xfoil-dat` additionally writes the exact analytical closed section in XFOIL/Selig order, so an independent reference code can analyse the same geometry rather than XFOIL's finite-gap built-in profile. This is a separate analytical test-geometry source; ParaCFD never extrudes an imported paraglider surface or substitutes this geometry for the supplied canopy.

## Grid and fields

The new grid path is static block-structured Cartesian AMR with refinement ratio 2:1. A brick has uniform cells and compact metadata: level, integer coordinate, origin, spacing, six same-level neighbours, parent, children, and boundary/embedded-boundary flags. Per-level integer-coordinate hash tables locate bricks without tree traversal or binary searches.

Fields use pooled, contiguous Structure-of-Arrays storage per AMR level. Production `Real` is `float`; `PARACFD_VALIDATION_FP64=ON` changes the new numerical path to `double` for validation. Geometry preprocessing and global validation calculations may still use double precision. A GPU-resident per-level coordinate hash locates the finest brick and local cell directly.

The implemented AMR path includes same-level halo exchange, ratio-two restriction/prolongation, aperture-aware flux matching, hierarchy balancing, and one matrix-free composite pressure operator spanning all active levels. Coarse/fine faces are compact four-tile connections; ordinary same-level faces remain implicit structured stencils. After transport, every compact tile gathers its collocated fine MAC velocity; after projection, corrected tiles scatter to the fine faces and their aperture-weighted mean is written to the coarse face.

`ExternalAeroCore` owns the static hierarchy/topology and persistent device fields. The production timestep advances one vector momentum state per actual fluid control volume with conservative finite-volume fluxes. Regular same-level faces use an implicit structured minmod-MUSCL stencil; compact regular/fragment and 2:1 faces reconstruct the donor state at the real face centroid from a precomputed same-side least-squares gradient and clamp it to the connected endpoint range. The same flux is applied with opposite sign to both endpoint volumes. This is followed by same-topology molecular/Smagorinsky diffusion, implicit two-sided fabric wall shear, pressure-compatible face reconstruction, external boundary conditions, and one composite projection. Advective CFL is the maximum sum of outward volumetric flux divided by the owning control-volume volume, including regular, EB, coarse/fine, and physical-boundary faces. Explicit graph diffusion independently computes `max(sum(nu A/d)/V)` over those same open connections and conservatively subcycles at a 0.7 maximum-principle limit; short EB centre distances therefore cannot violate the diffusion timestep. No velocity cap or runaway guard is used. The older bounded MacCormack/RK2 implementation remains an explicit validation option only.

## Zero-thickness embedded boundaries

Regular cells retain implicit Cartesian topology. Only cells intersected by fabric receive compact irregular records:

- fluid fragments with independent pressure state, volume, centroid, and parent cell;
- fragment connections through open fluid;
- Cartesian-face apertures with area, centroid, and the fluid fragments they join;
- fabric surface patches with source triangle/face IDs, area, centroid, normal, and plus/minus fragments.

A smooth membrane cut produces two fluid fragments and no connection through fabric. Fabric exactly coincident with a Cartesian face becomes a blocked cut face between two full-volume regular cells; partial coverage is reconstructed into separate connected apertures. Complex finest-level cells use a configurable deterministic local fluid-connectivity graph whose edges are blocked by exact BVH intersections. This supports more than two fragments at ribs, sheet endings, and junctions without inside/outside filling or cross-fabric merging; any topology still unresolved is a hard preprocessing failure.

Independent EB aperture-normal velocities are advanced on a compact same-side graph. Structured MAC faces adjacent to each fragment supply the carrier state; their staggered momentum volume is the sum of the two adjacent fluid half-volumes, including same-side fragment merges, rather than an assumed `h^3`. Static preprocessing links nearest same-axis apertures into directed chains; complete upstream/upstream2/downstream chains use a minmod-limited MUSCL update, while sheet endings, junctions, and incomplete chains retain the bounded first-order donor fallback. Each velocity component is collocated at its area-weighted aperture/carrier sample position. Static weighted least-squares matrices then reconstruct the row-major `du_i/dx_j` tensor from the physical displacement between connected same-side samples. CPU preprocessing stores a symmetric pseudoinverse per fragment/component; production FP32 rejects eigenmodes with condition number above `1e4` instead of amplifying an unsupported seam direction. The symmetric tensor supplies `|S| = sqrt(2 Sij Sij)` to compact-region Smagorinsky viscosity. Molecular diffusion and that eddy viscosity are applied before projection. The combined explicit update is limited to the extrema of its actual same-side stencil, so transport cannot invent a new local maximum or minimum; there is no arbitrary absolute velocity cap, and the subsequent pressure projection remains free to create physically required extrema. The graph contains only actual fluid connections, so it cannot transport through fabric and it does not turn the regular domain into CSR.

Every surface patch also contributes to a separate compact two-sided fabric-wall work list, including a sheet exactly coincident with a Cartesian face and therefore having no compact aperture edge. Each side uses its own fluid-control-volume centroid and pressure DOF. The production wall path evaluates the arbitrary-orientation tangential velocity at each patch side and solves Spalding's smooth-wall law continuously through the viscous and log layers. It freezes that nonlinear coefficient over one timestep, sums every incident patch into a symmetric tangential drag matrix per control volume, and applies the three-component system with backward Euler. This is dissipative for any timestep and prevents multiple patches sharing a small control volume from explicitly overshooting and reversing its tangential velocity. Per-patch reaction is evaluated from the updated state, so the CAD force remains exactly opposite the fluid impulse and the two fabric sides never share a state. Manufactured low/high-Re residual, stiff-timestep dissipation/no-reversal, reversed-winding, CPU/GPU parity, and fluid-impulse/fabric-reaction gates pass in FP32 and FP64. The older implicit molecular no-slip sink remains as a separately tested validation path but is no longer applied on top of the production wall model.

Small fragments below `min_volume_fraction` (default 0.25 of a Cartesian cell) are conservatively merged through suitable open apertures to a larger same-side control volume. Fabric is never a legal merge connection. A 0.05 experiment retained substantially stiffer PlanB compact states, so 0.25 remains the stability-oriented default while resolution studies quantify its geometric influence. Apertures below `min_aperture_area_fraction * h^2` (default `1e-4`) are finite-resolution clipping slivers: preprocessing removes the matching velocity and pressure connection together and reports their count and cumulative atlas area. This threshold does not close a resolved CAD opening, and can be set to zero for geometry studies. Isolated sealed fluid components retain their pressure states and volumes; the composite solve assigns one explicit pressure gauge to every component not connected to the pressure-reference outlet.

## Pressure projection and aerodynamic loads

The matrix-free finite-volume pressure operator uses actual control-volume volumes and coefficients proportional to open area divided by centre distance. Regular/regular faces retain a structured fast path; EB apertures, blocked coincident faces, and 2:1 coarse/fine tiles are compact special cases. A sparse cross-brick atlas prevents brick boundaries from becoming physical walls and augments one composite pressure graph spanning every level. CPU reference and FP32/FP64 CUDA operator implementations share the topology. A persistent GPU projection performs divergence assembly, RHS formation, one composite PCG solve, pressure scatter, and conservative regular/special-flux correction without bulk field transfers. The PCG preconditioner combines the fine diagonal with an additive level-zero Galerkin aggregate solve; compact nonlocal aggregate edges retain conservative fragment-merge topology. Each active fluid component that cannot reach the pressure outlet receives a deterministic gauge. GPU boundary kernels prescribe +X freestream, use an X-max pressure reference/zero-gradient velocity, and apply the same free-slip far-field condition at both Y and both Z boundaries; there is no ground branch.

Every owned composite surface patch retains its global plus/minus pressure DOFs and CAD triangle/face provenance. Surface pressure results retain `p_plus`, `p_minus`, `delta_p`, the corresponding Cp values, and pressure force per source triangle. Smooth-wall shear force is accumulated independently per triangle and whole-wing force/moment; pressure, viscous, and total D/S/L components remain separately available. Whole-wing accumulation uses double precision. With freestream along +X, drag, side, and lift axes are +X, +Y, and +Z. Coefficients are reported only when the user supplies a positive reference area.

## Visualization collision

The Qt/OpenGL viewer still displays the STEP surface. Flow particles and tracers can use the placed triangle BVH for segment-crossing tests and cannot pass through fabric. This does not use an inside-solid or parity classification. The mesh renderer accepts per-source-triangle delta-Cp through an OpenGL shader-storage buffer indexed by primitive ID, so shared CAD vertices do not smear results across fabric panels. Canopy colour auto-range uses the finite-value 99th percentile of absolute Cp/delta-Cp and explicitly labels that display range; sharp-edge outliers saturate rather than flattening the entire wing into the green midpoint, while stored values and force integration remain unchanged. A dedicated worker now advances `ExternalAeroCore`, throttles surface/conservation downloads, publishes delta-Cp automatically, and reports separate pressure, smooth-wall skin-friction, and total loads plus CFL, regular/compact-EB velocity maxima, projection convergence, divergence/flux diagnostics, and persistent GPU memory. The scalar plane samples the finest active AMR brick at every display vertex from the throttled per-level host snapshot; its two axis-dependent dimensions are derived from the domain extent and finest active cell spacing rather than a fixed square resolution, with a bounded visualization-only allocation cap. Pressure samples inside cut cells select the actual local fluid-fragment DOF rather than the inactive parent Cartesian slot, so the two sides of a zero-thickness sheet remain independent in the slice. The overlay states the current sample dimensions and finest `h`. Arrows and tracers intentionally retain a cheaper coarse 3-D display field. The default camera fits the placed wing; `Fit Wing` and `Fit Domain` explicitly separate close aerodynamic inspection from inspection of the longer downstream wake volume. Live controls expose animated 3-D/2-D arrows, a stationary regular vector lattice, and tracer mode/density/length/width/boring-filter settings. `2D Section` looks normal to the active slice, clips the camera-side half of the STEP surface, disables tracers, and selects the black vector lattice over the scalar plane. The scalar plane never writes depth, so 2-D arrows and tracers remain fully visible over it while the opaque STEP canopy still occludes flow glyphs on its far side. Editors ignore ordinary wheel input so scrolling the compact settings dock cannot silently change simulation or visualization values.

The 3-D run-state overlay always shows CFD step, physical simulation time, and wall time since `Build CFD Grid + Run`; a paused display therefore retains both the simulated duration and the actual time to its exit decision. Every auto-paused run, including an ordinary single-angle run, uses the same bounded exit policy: it may exit because the full field is steady, because time-weighted mean forces in adjacent half-flow-time windows agree within the configured tolerance, or because the configured maximum number of streamwise-domain flow-throughs has been reached. The maximum-flow endpoint is reported as `MAX FLOW — NOT CONVERGED`, never as settled or converged, and retains an explicitly labelled time-weighted final-window force when available. The ordinary load readout displays that same converged, bounded, partial, or instantaneous run-result classification used by an AoA sweep, so the endpoint is not silently represented by the last instantaneous sample. An evolved pressure-projection failure is a solver error and cancels a sweep; it is never presented as a manual or converged pause. The AoA sweep treats the current CAD placement as the explicit 0-degree baseline, pitches about world Y, and rebuilds static AMR/EB topology for every requested angle. Sweep rows record D, L, force L/D, optional CD/CL, physical time, wall time, and exit reason. The whole-wing reference-area input is next to the sweep. A positive area enables coefficients but never changes forces; zero continues to withhold CL/CD rather than inventing an area convention.

The purpose-built paraglider window controls density/viscosity, face-bbox domain margins, base spacing/level count, surface/wing/wake refinement, CFL, Smagorinsky coefficient, projection tolerance/iterations, and optional aerodynamic reference values. `Build CFD Grid + Run` reconstructs the static hierarchy, initializes pressure, and immediately starts continuous CFD; Play/Pause and Step control the resulting worker. Successful STEP/config loads are persisted in a ten-entry `File -> Recent files` menu; an ordinary no-argument startup restores the most recent existing wing/config and its confirmed placement, but deliberately does not build or run CFD. Missing recent paths are pruned. A clearly labelled cropped-Y diagnostic clips the oriented open fabric to a selectable span station and requested physical Y width, rounds the width upward to an integer number of configured finest cells, selects a Y-normal 2-D view, and displays the cell count/current step prominently. It uses the real uniform EB/pressure/timestep path but is a collapse-localization tool, not a physical whole-wing result; its runtime crop and uniform-grid overrides are not serialized into the normal wing config. A separate half-wing mode clips the oriented +Y span half without cap triangles, anchors Y-min exactly on the wing centre, and uses the existing zero-normal-flow/free-slip boundary as a mirror plane. Integrated pressure/viscous loads are mirrored back to whole-wing values while per-triangle Cp remains the actually simulated half. This mode is valid only for symmetric geometry at zero sideslip and deliberately suppresses antisymmetric wake modes. The internal freestream velocity remains +X, so the leading edge must face upstream toward -X. On direct STEP load, the longer horizontal face-only bbox axis is treated as span and the shorter as chord; the current exporter convention assumes the negative chord direction points toward the leading edge and maps it to upstream -X. A prominent 180-degree LE/TE flip remains because bbox extents cannot determine chord polarity. Config files store the confirmed placement matrix and do not re-infer it. GUI and command-line preprocessing share one brick-aligned zero-origin framing helper; placement is canonicalized to the FP32 display/production-mesh frame before clipping so both paths build identical EB topology. EB atlas geometry halos are clamped at physical-domain boundaries, so a small fragment cannot merge into a nonphysical halo cell when fabric meets a cropped-domain boundary.

For half-wing symmetry, any original CAD triangles lying wholly in the mirror plane are omitted because the physical symmetry boundary already supplies their zero-normal-flow condition and there is no opposite pressure volume inside the half-domain. Skins crossing the plane remain clipped and open; no closure triangles are generated.

## Build and test

The RTX 4090 development configuration is:

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_CUDA_ARCHITECTURES=89
cmake --build build
ctest --test-dir build --output-on-failure
```

The repository may already contain a Visual Studio build directory; preserve and use its established generator rather than reconfiguring it in place.

Important probes are:

- `paraglider_geometry_probe`: deterministic geometry, EB topology, pressure/operator, AMR exchange, FP32 parity, and load tests;
- `paraglider_gpu_probe`: CUDA pressure-operator timing and allocation estimates;
- `paraglider_flow_probe`: dynamic normal/parallel/inclined plates, projection divergence, opened-cavity connectivity, and AMR-versus-uniform force comparison;
- `paraglider_probe`: STEP/config preprocessing diagnostics;
- `paraglider_case_probe`: imported-wing multi-step force, CFL, conservation, and performance history (manual long-running diagnostic);
- `naca_step_generator`: OpenCascade STEP generator for any valid four-digit NACA code, with configurable chord/span/section sampling;
- `naca_validation_probe`: long-running four-profile lift gate against exact-geometry MIT XFOIL 6.99 polars, with uniform/local-AMR and grid-phase diagnostics;
- `parity_probe`: CPU/GPU parity and immutable snapshots for the reusable FP64 uniform-MAC reference kernels.

`paraglider_case_probe --physical-time T --max-levels N` runs an imported wing to a common physical time instead of comparing arbitrary step counts. If `--steps` is also given it is a hard safety limit and failure to reach `T` returns nonzero. A final `[paraglider-case-summary]` line is stable key/value output for convergence scripts; velocity maxima on that line are explicitly labelled pre-step because they are the values used to choose the final CFL timestep.

`paraglider_case_probe --thin-y-fraction 0.5 --thin-y-width 1.0` reproduces the GUI's cropped-Y centre-span diagnostic. Width is in metres and snaps upward to whole finest cells; the default remains 0.125 m (two cells for the checked-in PlanB configuration).

`configs/paraglider.json` is the new configuration reference.
`configs/planb_parakite.json` is the checked-in PlanB acceptance case; its -90-degree Z placement maps the confirmed leading-edge direction (-Y) to ParaCFD upstream (-X), against the +X freestream velocity.
`configs/naca_validation.json` plus the four checked-in `Test-Data/NACA*_C1_S2p03.step` files define the 0012/2412/4415/4112 coefficient suite. Regenerate a profile and its independent-reference coordinates with, for example, `naca_step_generator --naca 4415 --chord 1 --span 2.03 --points-per-side 129 --output NACA4415.step --xfoil-dat NACA4415.dat`. `configs/naca2412.json` remains the fast imported-geometry topology regression.

## Solver path status

The production solver is the face-centred staggered MAC path. It is the default in
`ExternalAeroCore`, the GUI, `paraglider_case_probe`, and `naca_validation_probe`.
It uses bounded MacCormack advection in regular bricks, precomputed exact-BVH
same-side links near fabric, compact EB-aperture transport, Smagorinsky diffusion,
optional two-sided Spalding wall shear, and one composite GPU pressure projection.
The same-side preprocessing remains exact; the former 75-second PlanB startup was
an O(N²) coarse/fine-link deduplication bug. Hash deduplication reduces complete
PlanB preprocessing to about 9 seconds without changing fabric crossing tests.

The collocated conservative control-volume momentum path is retained behind the
explicit `--conservative-momentum` / `--conservative-cell-momentum` development
option and the GUI checkbox `Experimental collocated CV momentum`. It is not a
production solver: high-incidence imported-wing cases develop an incompatible
cell/face pressure mode. No velocity clamp or runaway guard is used. The paragraphs
below record that experiment's implemented mathematics and test coverage, but any
statement in them calling it the default, production, or long-run validated path is
superseded by this paragraph.

The experimental collocated path advances one vector momentum state per regular cell or split fluid fragment, while projected Cartesian/aperture velocities remain mass-flux states. It includes same-side molecular/Smagorinsky diffusion, two-sided Spalding shear, external boundaries, composite projection, and Rhie-Chow-like pressure-compatible reconstruction. Its manufactured conservation/parity tests remain active. It must be selected explicitly and is not accepted for imported-wing results.

The pressure feedback is not a runaway guard or velocity cap. Each persistent cell component receives the aperture-area-weighted mean of the exact face-normal pressure correction applied by the composite projection, including compact regular/fragment perimeter connections as well as EB and coarse/fine apertures. A generic least-squares gradient and a direct raw pressure-traction update were rejected on the imported wing because highly non-orthogonal merged-fragment geometry made those cell updates incompatible with the projected face fluxes. The direct traction operator remains a manufactured force/reaction reference. Conservative CFL now uses the exact maximum control-volume donor rate, `sum(outward volumetric flux) / volume`, over regular faces, EB apertures, coarse/fine tiles, and physical X boundaries.

On the current 47,997-triangle PlanB fixture, a full-wing +12-degree production face-MAC run remains bounded through 1,200 steps. It gives pressure-only `[D,L]=[184.05,537.08] N`, regular/compact maxima `14.31/18.57 m/s`, max/RMS divergence `1.55e-3 / 5.25e-6 s^-1`, and net integrated flux error `-3.20e-6 m^3/s`. The last step takes 98.0 ms including 54.3 ms projection, PCG converges in 80 iterations to `9.996e-6`, and persistent GPU storage is 518.75 MiB. This is a stability and conservation record, not a converged paraglider load or a substitute for the NACA coefficient gate.

The coefficient benchmark crops the generated extrusion to a 0.125 m spanwise slab and places free-slip boundaries on both slab sides, representing a two-dimensional section while still exercising ParaCFD's three-dimensional EB/AMR code. It uses 10 m/s, chord 1 m, `Re=666667`, `Mach=0.029`, 0.8 s physical time, and averages the final 0.2 s. Official MIT XFOIL 6.99 loads coordinates emitted by the same generator and supplies inviscid, natural-transition, and transition-forced-at-1%-chord context. The accepted production gate uses slip fabric and compares pressure lift to the inviscid XFOIL column. This is the only defensible like-for-like target until ParaCFD has a validated boundary-layer transition and separation model; the natural and forced-transition columns remain visible diagnostics and are never selected after a run. The accepted local-AMR path uses `h=0.00390625 m` (256 cells/chord), a physical 0.15 m finest-cell collar, a fixed 0.25 small-fragment merge threshold, exact surface-area coverage, one sealed-interior pressure gauge, volume-weighted divergence and integrated-flux gates, and an independent circulation/lift check. The declared FP32 pressure-lift envelope is `max(0.03, 15% |CL_XFOIL,inviscid|)`. Grid phase is an explicit topology diagnostic; a half-cell phase avoids vertex/cusp coincidence with Cartesian planes without changing geometry or resolution. `naca_validation_probe` is deliberately not a default CTest because the high-resolution transient suite is long on the RTX 4090.

The completed four-profile +4-degree production gate passes with 0 failures. `CL_ParaCFD / CL_XFOIL,inviscid` is `0.50388 / 0.4828` for NACA0012 (`+4.37%`), `0.70650 / 0.7414` for NACA2412 (`-4.71%`), `0.93052 / 1.0273` for NACA4415 (`-9.42%`), and `0.83188 / 0.9192` for NACA4112 (`-9.50%`). Circulation-derived coefficients are `0.49312, 0.69069, 0.92066, 0.82247`; every case has exact represented coverage and one sealed-interior gauge. Normalized maximum/local flux defects stay below `1.92e-4` of a finest freestream face flux and volume-weighted normalized RMS divergence below `3.0e-8`. Persistent storage is 420--456 MiB and measured production steps take 68.6--112.6 ms on the RTX 4090. This validates attached inviscid pressure lift only.

The older 12-point smooth-wall matrix is retained only as historical development evidence. Its apparent agreement with transition-forced XFOIL did not validate the wall model, transition, separation, or drag, and it was produced by the collocated solver that is no longer the production path.

## Current limitations

ParaCFD is now a paraglider-only application, but it must not yet be described as producing trustworthy end-to-end paraglider aerodynamic results:

- The strict shared-face geometry transaction preserves a manufactured
  `3.4911e-16 m^2` confirmed-free vent and now produces zero explicit false apertures
  for the closed-cylinder roundoff case. Preserving source-triangle lineage on the
  analytic plane reduced wrong pressure-owner pairings from 2,348 to 1,292, but the
  audit is still not complete: fitted analytic planes can disagree with an adjacent
  cell's piecewise curved traces. The tracked NACA 2412 strict case also remains unresolved.
  The default GUI therefore remains a clearly labelled qualitative preview. Do not
  repair this with an area threshold or a global source-face side mask; the required
  proof needs a piecewise trace-to-fragment face-region adapter with certified attached
  versus free edges.

- EB that reaches a 2:1 interface is currently rejected instead of receiving aperture-aware cross-level fragment reconstruction. The tested PlanB hierarchy keeps its EB atlas away from these interfaces.
- Optional topology-only surface levels resolve sharp cusps without changing the ordinary flow-collar resolution, but the current two-level pressure preconditioner makes their transient cost excessive (the NACA4112 h/512 topology fixture is about 3.54 million pressure states and 1.39 s per projected step). They are presently a preprocessing/topology escape hatch, not a practical production-resolution control.
- The composite solver has a two-level additive geometric/Galerkin preconditioner, not yet a complete recursive multigrid hierarchy. The checked-in PlanB initial projection converges at the configured global residual tolerance, but local maximum divergence remains sensitive to the very small irregular control volumes and needs a stricter local/conservation acceptance criterion.
- The production external-aero timestep is globally conservative over its explicit regular, EB, coarse/fine, and physical-boundary flux ownership. Its structured and compact MUSCL reconstructions are bounded and second-order on complete smooth stencils, but reduce locally at extrema, junctions, boundaries, and incomplete EB stencils. Airfoil results therefore still require a documented grid-convergence study; 128 cells/chord is not generally sufficient for a highly cambered leading edge.
- Production uses the face-centred finite-volume/MacCormack path and its exact static BVH fabric-band mask. The collocated control-volume vector path is experimental until its imported-wing cell/face pressure coupling is repaired and revalidated.
- Compact EB aperture velocities use bounded minmod-limited MUSCL transport on complete same-axis graph chains, with a first-order donor fallback where a chain ends or branches, plus molecular diffusion and component-collocated weighted least-squares reconstruction of the full velocity-gradient tensor. Conservative 0.25-volume merging stabilizes tiny same-side fluid fragments. The configurable `1e-4 h^2` aperture value is diagnostic only: every positive-area aperture remains in the pressure/flux graph, because an area cutoff would silently seal physical vents and is not invariant to polygon subdivision. Tests cover a smooth quadratic characteristic, uniform-state preservation, local bounds, LES dissipation, tangential shear, rigid rotation, normal extension, exact affine reconstruction, winding-invariant inclined no-slip damping, wall flux on a face-aligned membrane with no compact apertures, and production Spalding smooth-wall flux/traction in both viscous and high-Re regimes. Grid/domain/force convergence is still required before trusting loads.
- The earlier compact-momentum validation operator reconstructs fragment vectors from aperture and physical-carrier half masses. It proves equal/opposite internal transfer (`1.19e-7` FP32, zero FP64), exact perimeter mass-flux ownership, and unique same-level carrier aliases, but it is not a promotable regular/EB mortar: composing its truncated regular-carrier ring with the structured update changes a uniform carrier state. That failed free-stream gate is why `ExternalAeroCore` does not call it. The replacement stores one vector momentum state on each actual pressure control volume (ordinary cell or split fragment), while the projected MAC/aperture velocities remain the mass-flux DOFs. Ordinary same-level connections run through implicit brick CUDA kernels; only 2:1 tiles and regular/compact EB connections are materialized, so this is not a full-domain sparse graph. The same upwind or diffusive flux updates both endpoint volumes. The one-level membrane fixture preserves freestream exactly and closes CPU/GPU conservation plus analytical external export. On the three-level fixture, 1,536 coarse/fine pressure-flux tiles preserve freestream exactly; a perturbed state changes by `8.18e-4`, has CPU/GPU state error `1.49e-8` in FP32 (zero FP64), and conserves integrated momentum to `1.42e-7` FP32 storage rounding / `4.44e-15` FP64. External boundary ownership uses explicit physical-domain flags, preventing an internal coarse/fine interface with no same-level neighbour from becoming a false inlet/outlet. Molecular and Smagorinsky diffusion reuse the same open-face ownership and non-orthogonal pressure conductance. Ordinary cells use a structured gradient kernel; only nodes touching EB, cut faces, surface patches, or 2:1 interfaces enter a compact weighted least-squares gradient list (1,818 nodes and 11,896 incidences in the manufactured three-level case). Affine shear is recovered to `8.94e-11` FP32 / roundoff FP64, rigid rotation produces no eddy viscosity, EB/multilevel perturbations dissipate energy while conserving momentum, and a face-aligned membrane cannot mix two different constant side states. Repeated composed transport -> LES -> reconstruction -> projection -> pressure-impulse gates preserve uniform flow and zero divergence exactly for 20 one-level EB steps and 10 three-level AMR steps. Smooth-fabric shear now acts directly on each side's control-volume vector through the arbitrary-orientation Spalding law and retains the opposite CAD force; the manufactured impulse is dissipative, winding invariant, and closes fluid/fabric reaction to `6.42e-7` FP32 / `4.52e-14` FP64 with exact CPU/GPU state parity. With the actual X-max pressure outlet, a 20-step nonuniform wall/LES/transport/projection loop converges below `6.6e-7` relative residual and to `1.19e-7 s^-1` max divergence in FP32 (FP64 `5.93e-12` and `4.44e-16`). An earlier all-Neumann version was correctly rejected because external inflow/outflow made its RHS incompatible. This state remains validation-only until imported-wing long-run and performance gates pass.
- On the current 47,997-triangle PlanB working fixture with the confirmed leading edge facing upstream, the production face-MAC path remains bounded through a 1,200-step full-wing +12-degree run and through the complete seven-angle half-wing sweep. The latter gives monotonically increasing mean lift from `-327.40 N` at -6 degrees through `-14.03 N` at 0 degrees to `553.87 N` at +12 degrees. Loads remain resolution-, domain-, wall-model-, and symmetry-dependent; full grid/domain/force convergence is necessary before using the polar for design.
- Cell-to-flux reconstruction and reverse pressure coupling are implemented without a smoothing round trip. Ordinary faces remain implicit; compact regular/fragment, 2:1, and EB faces interpolate the normal component at the real face position between actual control-volume centroids. CPU/GPU reconstruction errors are `1.49e-8` FP32 and roundoff FP64, including all 1,536 multilevel tiles. A face-aligned membrane remains exactly zero-flux with opposite side states. Composite projection reduces a deliberately divergent reconstruction from `1.4` to about `4.5e-5 s^-1` in FP32 (`3.83e-11` FP64). Its GPU pressure acts directly on persistent control-volume momentum: open faces get paired opposite finite-volume impulses and fabric applies `+p_plus A n` / `-p_minus A n` to its two fluid sides, exactly opposite the winding-invariant CAD load. The closed two-pressure fixture balances pointwise; the 1,536-tile impulse conserves to `3.74e-9` FP32 / `5.12e-15` FP64 with CPU/GPU error `1.67e-8` / `2.78e-17`.
- The first equal-physical-time PlanB gate at about 0.100 s gives pressure-only `[Fx,Fz]` of `[180.2,-8.17]`, `[200.6,-5.25]`, and `[203.3,-24.77]` N at 0.125, 0.0625, and 0.03125 m finest spacing. Streamwise force changes 11.3% then 1.4%, but vertical force is plainly unconverged and the flow is still transient. These values establish a reproducible blocker; they are not an aerodynamic result.
- The Qt viewer displays live velocity/pressure slices, arrows, fabric-stopped tracers, AMR/EB boxes, and triangle-native visible-side Cp, Cp+, Cp-, or delta-Cp. The scalar slice is finest-brick aware and its per-axis sample counts follow finest cell spacing, but visualization still uses throttled host snapshots and OpenGL uploads rather than direct CUDA/OpenGL interop; arrows and tracers use a coarse uniform 3-D display copy.
- The GPU Spalding smooth-wall flux affects production flow and publishes separate viscous and total loads. Its smooth-wall assumption has not been calibrated for a real fabric roughness, and the whole solver still lacks grid/domain/force convergence.
- The opened-cavity gate measures developed bidirectional flow through a deliberately missing fabric face while the closed control has zero represented opening flux. Longer internal-pressure and force-convergence studies on resolved paraglider geometry remain outstanding.

The former building, binary-solid voxel, ground/channel, seabed, porous, scene, and building GUI paths have been removed. Only mathematically reusable uniform-MAC FP64 kernels remain as validation references; they are not linked into the production external-aero timestep.
